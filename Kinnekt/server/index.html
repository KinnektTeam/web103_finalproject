LocalMeet API

Express + PostgreSQL backend for the LocalMeet app. All responses are JSON.

Checking database…

Categories

Interest colors used by the color picker and event badges.

GET/api/categoriesList all colors

Events

Browse, create, edit, and cancel events.

GET/api/eventsUpcoming events. Filters: category_id, group_size, max_cost, life_stage, attendee_id (highlight matches), include_past=true
GET/api/events/:idOne event with attendees grouped by RSVP status
POST/api/eventsCreate an event (date must be in the future). The organizer is added as “going”.
PATCH/api/events/:idUpdate some or all fields
DELETE/api/events/:idCancel an event (its RSVPs are removed too)

RSVPs

RSVPing again with the same email updates the status instead of creating a duplicate.

GET/api/events/:id/rsvpsList RSVPs for an event
POST/api/events/:id/rsvpsBody: { name, email, status }, where status is going, maybe, or not_going
DELETE/api/events/:id/rsvps/:attendeeIdRemove an RSVP

Attendees

Profiles, interest colors, and “Find your people”.

GET/api/attendeesFilters: life_stage, category_id, similar_to (people who share colors with an attendee)
GET/api/attendees/:idProfile with interests, organized events, and RSVPs
POST/api/attendeesBody: { name, email, life_stage?, interest_ids? }
PATCH/api/attendees/:idUpdate name, email, or life stage
DELETE/api/attendees/:idDelete an attendee
GET/api/attendees/:id/interestsAn attendee’s chosen colors
PUT/api/attendees/:id/interestsReplace chosen colors. Body: { category_ids: [1, 3] }

Resources

Local resources such as student housing, jobs, study spots, and recovery programs.

GET/api/resourcesFilters: category_id, cost_level (free, low, medium, high), sort=cheapest
GET/api/resources/:idOne resource
GET/api/resource-categoriesList resource categories

Maintenance

Non-RESTful action.

POST/api/resetDrop and recreate all tables with the sample data. Deletes everything users have added.
Multiple filter values can be comma-separated, for example ?group_size=small,one_on_one.
